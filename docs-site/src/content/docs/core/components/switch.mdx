### Accessibility
- renders a real &lt;button role="switch"&gt; with aria-checked, so Space and Enter operate it and a screen reader reads the state  
  <small><a href="https://github.com/Aye-Kyawt/lumo-design-system/blob/aa6635fbc068f4b7388080dfc48f2197204ad7d1/src/components/switch/switch.jsx#L19">src/components/switch/switch.jsx:19</a></small>
- uses aria-disabled rather than the DOM disabled attribute, so a disabled switch stays focusable and can still be read  
  <small><a href="https://github.com/Aye-Kyawt/lumo-design-system/blob/aa6635fbc068f4b7388080dfc48f2197204ad7d1/src/components/switch/switch.jsx#L78">src/components/switch/switch.jsx:78</a></small>
- the node carries no label layer, so the accessible name must come from the caller via aria-label or aria-labelledby  
  <small><a href="https://github.com/Aye-Kyawt/lumo-design-system/blob/aa6635fbc068f4b7388080dfc48f2197204ad7d1/src/components/switch/switch.jsx#L22">src/components/switch/switch.jsx:22</a></small>
- the knob is aria-hidden; the parent button is the control, so the knob must not be focusable or announced  
  <small><a href="https://github.com/Aye-Kyawt/lumo-design-system/blob/aa6635fbc068f4b7388080dfc48f2197204ad7d1/src/components/switch/switchKnob.jsx#L18">src/components/switch/switchKnob.jsx:18</a></small>

### Props
| Prop | Type | Default | Notes |
|---|---|---|---|
| `on` | `boolean` | — | Figma `On`. Supply it to drive the switch from your own state; leave it out and the switch keeps its own, seeded from `defaultOn`. |
| `defaultOn` | `boolean` | `true` | Starting value when `on` is not supplied. Defaults to `true`, which is the Figma set's own default variant (17:1202). |
| `disabled` | `boolean` | `false` | Not a variant in Figma — see docs/switch.md, gap 3. Blocks the change and is announced, while the control stays focusable so it can be read. |
| `onChange` | `(on: boolean, event: React.MouseEvent) =&gt; void` | — | Called with the value the switch is moving to. |
| `className` | `string` | `''` |  |
