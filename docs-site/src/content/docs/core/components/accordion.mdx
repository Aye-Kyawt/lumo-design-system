### Props
| Prop | Type | Default | Notes |
|---|---|---|---|
| `state` | `'closed'|'open'` | — | Figma `State`. Supply it to drive the accordion from your own state — an FAQ list that allows only one open answer does exactly that; leave it out and the accordion keeps its own, seeded from `defaultState`. |
| `defaultState` | `'closed'|'open'` | `'closed'` | Starting value when `state` is not supplied. Defaults to `closed`, which is the set's own first variant (208:4897). |
| `title` | `string` | `''` | The header text (208:4899 / 208:4906). `title` is also a global HTML attribute, so the DOM one is exposed separately as `htmlTitle` — see docs/naming-conflicts.md for why the Figma name keeps the prop. |
| `htmlTitle` | `string` | — | The DOM `title` attribute, i.e. the browser's own hover tooltip. Nothing in the node asks for one; this is the escape hatch that keeps `title` free for the Figma property. Unset by default. |
| `disabled` | `boolean` | `false` | Not a variant in Figma — see docs/accordion.md, gap 1. Blocks the toggle and is announced, while the header stays focusable so it can be read. |
| `iconName` | `string` | `'expand_more'` | Material Symbols glyph for the chevron. Defaults to `expand_more`, which is what node 208:4895 draws. |
| `headingLevel` | `number` | `0` | Not a Figma property and not claimed to be one. The node draws a card, not a document outline, so it has no heading level. Pass 1–6 to wrap the header button in that heading element, which is what lets a screen reader user jump between the questions in an FAQ list. Defaults to `0` — no wrapper — so the default output is exactly what the node draws. |
| `onToggle` | `(state: 'closed'|'open', event: React.MouseEvent) =&gt; void` | — | Called with the state the accordion is moving to. |
| `children` | `React.ReactNode` | — | The content region — the `_Slot/Content` instance (41:21) in the `open` variant. Named `children` per the Card precedent in docs/naming-conflicts.md, since the accordion has exactly one slot. |
| `className` | `string` | `''` |  |
| `id` | `string` | — | Seeds the ids the button and the panel need to point at each other. Generated when absent. |

### Union types
- `state`: `'closed'|'open'`
- `defaultState`: `'closed'|'open'`
- `onToggle`: `(state: 'closed'|'open', event: React.MouseEvent) =&gt; void`
