### When to use it
> Use an empty state when a list, card or page has nothing to show — no results, nothing created yet, a failed load, or no permission.

<small>From the Lumo.Web.Component.V1.0.Complete library — the `empty-state` description, read 2026-10-19.</small>

### Where it goes
- in the empty region of a list, card or page

### When not to use it
- Don’t leave the user without a next step; always give the action.
  - **No alternative named.** The source states the prohibition without saying what to reach for instead.

### Props
| Prop | Type | Default | Notes |
|---|---|---|---|
| `size` | `'sm'|'md'` | `'sm'` | Figma `Size`. Picks the medallion size and the title/description type styles. |
| `title` | `string` | `'No use cases match these filters'` | Figma `Title`. The headline. Always shown — the node has no boolean for it. |
| `description` | `boolean` | `true` | Figma `Description` (the boolean property). Shows the supporting line. |
| `descriptionText` | `string` | `'Try removing a filter, or ask our team to research a custom use case.'` | Figma `Description` (the text property). Renamed because the set spells two different properties `Description`; see docs/naming-conflicts.md. |
| `action` | `boolean` | `true` | Figma `Action`. Reveals the `↳Action` slot. |
| `children` | `React.ReactNode` | `null` | The `↳Action` slot. Put a `Button` here — the component description says to always give the user a next step. Named `children` per the Card precedent in docs/naming-conflicts.md, because `action` is taken by the boolean above. |
| `icon` | `React.ReactNode` | `null` | The `↳Icon` slot. Swaps what sits inside the medallion. Defaults to the node's own `Icon/check` instance (94:10 / 94:18). |
| `iconName` | `string` | `'check'` | Material Symbols glyph for the default icon, when `icon` is not supplied. |
| `titleAs` | `'p'|'h1'|'h2'|'h3'|'h4'|'h5'|'h6'` | — | Not a Figma property. The node's title is a text layer, so `p` is the faithful default; pass a heading tag when the empty state owns a region of the page and a screen reader should be able to jump to it. |
| `className` | `string` | `''` |  |
