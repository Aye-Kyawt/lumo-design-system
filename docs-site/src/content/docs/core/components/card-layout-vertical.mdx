<TabItem label="Usage">
### When to use it
> Card layout. Stacks header, body and footer down the card — the default arrangement used across Lumo screens.

<small>From the Lumo.Web.Component.V1.0.Complete library — the `card/layout/vertical` description, read 2026-10-19.</small>

### Where it goes
- inside Card, filling its Layout slot

### When not to use it
- Don’t use it when the card leads with an image or chart; use card/layout/horizontal.
  - **Use instead:** `card/layout/horizontal` — not implemented in this library yet.
