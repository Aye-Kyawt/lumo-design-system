title: Request a feature
description: How to request a component or a feature.
---
Open an issue on **[Aye-Kyawt/lumo-design-system](https://github.com/Aye-Kyawt/lumo-design-system/issues)**.

## A new component starts in Figma

Components are built from Figma nodes, one node at a time. A request for a component that does not exist in the design library is a request to the designer first — there is nothing to build from until the node and its description exist.

Five components are already named by existing usage guidance and do not exist yet: `Chip`, `Checkbox`, `Spinner`, `Modal` / `Alert`, and `card/layout/horizontal`. If you need one of those, say so on the issue — the guidance already points at it.

## A new prop or variant

Say what you are trying to build and what the component stops you doing. Props match the Figma property names exactly, so a new variant usually means a new variant in the design set rather than a prop invented in code.

## What will be asked back

Whether the behaviour belongs in the system or in your app. A component that exists to serve one screen is usually that screen's code.
